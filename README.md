## 先定机房，再谈配置

客户在哪，机房就选哪。欧美买家从洛杉矶读取页面，延迟低，Google 爬虫抓取也顺；客户集中在东南亚、日韩或者分布很散，香港的互联节点更多，延迟更稳。

代价在带宽上。香港机房普遍给 5 到 20Mbps，美国机房 50 到 300Mbps 是常态。纯展示型的外贸站，产品页加询盘表单，香港这点带宽够用；站内有产品视频、大量高清图或者资料下载，美国机房更合适。

线路这一层影响的是你自己登录后台的体验。CN2 GIA 是电信的高端线路，AS9929 对应联通，CMIN2 对应移动，三网优化指三家各走各的优化路径。买家在国外感受不到这些，国内运营团队天天开着后台传产品、改价格，线路差一档，卡顿就很明显。

备案这条可以放心：香港和美国服务器都不需要备案，只有中国大陆机房要。

## 不开放 80 和 443，决定了这些套餐的用途

官网在住宅 IP 产品的配置列表下方写了一句话：由于 IP 风控原因，住宅 IP 产品不开放 80 和 443 端口。

80 是 HTTP，443 是 HTTPS。这两个端口关掉，意味着域名解析过去也没用，浏览器打不开任何页面。这类产品设计的用途本来就不在公网建站，而是让人以一个真实美国家庭宽带用户的身份去访问平台。

带 AS9929 优化的那两组限制更严。官网原文的意思是：产品拒绝所有外部探测和扫描，只允许白名单 IP 或者配置过端口转发的设备接入，没有中继 IP，没配置之前服务完全不可达。同时注明该产品的退款只退到网站余额，不原路返回。

这就把 SixtyNet 的产品线切成两半：

- **明确不能建站**：住宅 IP 四档、住宅 IP + AS9929 两档。前者端口关闭，后者需要白名单才连得上。
- **需要确认**：LAX-STARTER、LAX-MICRO、LAX-MEDIUM、LAX-Storage-500G 这一组，官网配置说明只写了 DDoS 防护，没有出现“住宅 IP”字样，也没写 80/443 限制。但它们的核数和内存档位、价格与住宅系列高度重合，第三方测评站里同型号的产品被归到了需要白名单接入的那一类。下单前找客服确认一句“80 和 443 是否开放”，比事后申请退款省事。
- **企业向产品**：Los Angeles China Unicom-Premium，走联通 AS9929，提供免费 BGP 会话配置、100M 基础带宽、3 倍突发和 95 计费，面向的是需要自己播 BGP、有独立带宽需求的业务，不是给单个网站用的。

**注册要手机验证，+86 号码收不到码。** 这条来自第三方测评站的记录，不是官网公示。如果你只有国内手机号，注册这一步就会卡住，先准备好能收短信的号码再动手。

**退款口径分产品。** 住宅 IP + AS9929 那两组明确写了只退网站余额。其余产品的退款条件官网没有统一说明，下单前问客服要一句书面答复。

**流量给得很大，但用不上也没意义。** 5TB 到 40TB 的月流量对建站来说远超需求。参考一组实测口径：50 到 100 个产品页、每页 2 到 3MB、每天 200 个访客，月流量大约 50 到 80GB。中型站每天 300 到 1000 访客，1 到 2TB 也够了。SixtyNet 这些套餐的流量配额是给高频访问平台、跑数据采集这类场景准备的。

**95 计费不是包月不限量。** Unicom-Premium 那条产品用的是 95th percentile 计费，带宽超出基础值要按峰值另外算钱，跟固定带宽的 VPS 完全不同的计费逻辑，买之前先弄懂。

## 1G 内存到底够不够

这个问题的答案取决于你装什么。

纯展示型 WordPress，配 Nginx 加缓存插件，1G 内存能跑起来，日常访问不会出问题。上了 WooCommerce，产品数在几百到一千这个量级，2G 起步更稳，订单插件和库存查询会吃掉不少内存。产品超过五千，或者站内有复杂筛选、多语言切换，4G 以上再说。

同一批资料里对这个问题的说法并不统一，有建议 1G 够用的，也有建议 4G 起步的。差别在于测试的是纯展示站还是带电商功能的站。按自己的站型对号，不用管别人给的那个单一数字。

香港和美国在这件事上还有个隐性差异：香港机房带宽小，页面加载慢，同样配置下并发承受能力更弱，内存给足一点更保险。
